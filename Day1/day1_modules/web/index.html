EXERCISE 03

리스트에서 짝수 찾기

정수 다섯 개를 리스트에 모으고, 2로 나눈 나머지가 0인 수만 찾아봅니다.

리스트 · append() · for · 나머지 연산 %
실행 결과
숫자 다섯 개를 입력하고 실행해 보세요.
Python 참고 코드
numbers = []
for i in range(5):
    number = int(input(f"{i + 1}.숫자를 입력하세요: "))
    numbers.append(number)

print("저장된 숫자:", numbers)
for number in numbers:
    if number % 2 == 0:
        print(number)

추가 과제 홀수도 찾고, 짝수가 몇 개인지 세어 보세요. 0과 음수도 입력해 보세요.

EXERCISE 04

반복문으로 만드는 구구단

각 열은 2~9단, 각 행은 곱하는 수 1~9입니다. 두 반복문이 표 하나를 만듭니다.

중첩 for · range() · f-string
실행 결과

버튼을 눌러 구구단 표를 만들어 보세요.

Python 참고 코드
for multiplier in range(1, 10):
    for dan in range(2, 10):
        print(f"{dan} X {multiplier} = {dan * multiplier}", end="\t")
    print()

추가 과제 사용자가 입력한 단 하나만 출력해 보세요.

EXERCISE 05

숫자 맞추기 게임

컴퓨터가 고른 1~100 사이의 정수를 맞혀보세요. 힌트를 보고 다음 숫자를 선택하세요.

random · while · if / elif / else · break
시도 횟수0번
현재 점수100점
실행 결과
게임이 준비되었습니다. 첫 번째 숫자를 입력하세요.
시도 기록
  1. 아직 입력한 숫자가 없습니다.
Python 참고 코드
import random

com_number = random.randint(1, 100)
count = 0
score = 100
while True:
    user_number = int(input("1~100 사이의 숫자를 입력하세요: "))
    count += 1
    score -= 10
    if user_number > com_number:
        print("컴퓨터보다 큽니다.")
    elif user_number < com_number:
        print("컴퓨터보다 작습니다.")
    else:
        print("정답입니다.")
        print(f"총 시도 횟수는: {count}번입니다.")
        print(f"최종 점수는: {score}점입니다.")
        break

점수 규칙 정답을 포함해 시도마다 10점 차감합니다. 원본처럼 11번째 시도부터 음수가 될 수 있습니다. 범위를 벗어난 입력은 시도에 포함하지 않습니다.
